# KRONOS

KRONOS is a multi-agent, explainable cybersecurity incident response assistant for IoT networks. This repository is the project root for the backend and planned frontend.

## Current status

- `backend/`: FastAPI service scaffold with a mock network-flow detector and API tests.
- `frontend/`: reserved for the frontend implementation.
- XGBoost model: trained separately and not yet integrated; the mock detector provides the planned prediction response contract in the meantime.

See [backend/README.md](backend/README.md) for installation, API, and test instructions.
