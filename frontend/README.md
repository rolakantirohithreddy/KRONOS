# KRONOS Frontend

The frontend for the KRONOS cybersecurity dashboard. Built with React, TypeScript, Vite, TailwindCSS v4, and Framer Motion.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Environment Variables
- `VITE_API_URL` - URL to the backend API (defaults to `http://localhost:8000`)
